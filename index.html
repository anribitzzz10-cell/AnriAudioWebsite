Audio to editable MIDI, with the original waveform still in view.

Analyze the performance, inspect MIDI against the source audio, edit the result, then drag or send it into your production workflow.

◉

Analyze

Run the main analysis pass and turn the available audio into an editable MIDI result.

▦

Piano Roll + Original Audio

See MIDI notes on the pitch/time grid while the original waveform stays aligned underneath.

✦

Edit notes

Move, resize, insert, delete, adjust velocity, and preview pitch while refining the result.

≈

Match Audio

Match MIDI velocity to the local loudness of the original performance for a more natural dynamic result.

⌗

Quantize + Snap

Clean timing with Quantize and Snap while keeping detailed control over note placement.

↗

Drag MIDI / Send MIDI

Drag the MIDI into the project or send the prepared result through the host workflow.

⇄

MIDI routing

Use host or external MIDI output, choose the MIDI channel, transpose, and constrain the pitch range.

⌕

Zoom + Preview

Fit the phrase, zoom horizontally or vertically, then play, stop, and seek while checking edits.

±

Creative MIDI tools

Use Randomise, Musical, Up +1, and Down -1 for fast variations and pitch adjustments.

Detection controls

Tune the analysis for different sources with dedicated controls.
