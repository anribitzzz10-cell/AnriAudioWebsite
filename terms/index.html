2. Product and compatibility

ANRI AUDIO MIDI is a software plugin for converting audio performances into editable MIDI notes, using ANALYZE, Piano Roll editing, Preview, Quantize, Snap, Drag & Drop and SEND MIDI in Logic Pro. The planned first commercial release is Audio Unit (AUv2) for macOS. A Windows VST3 edition is under separate development and is not included.
