**Это действующая спецификация checkout для сайта и ANRI Cloud, а не прежний план подключения.**

## Что ProEducation уже подтвердил

- Платёжная страница `https://anriprod.proeducation.kz/` **переведена в LIVE 27 октября 2026**. Повторно согласовывать подключение и вид деятельности «аудиоплагины» не требуется.
- **29 октября 2026** провайдер официально одобрил `sys=anriaudio` для самостоятельной интеграции `anriaudio.com` ↔ ANRI Cloud.
- Расчёт рекомендовано выставлять в **KZT**. Для оплаты картой РФ его реальные подписанные уведомления могут содержать `currency=rub`, несмотря на сумму и учёт заказа в тенге. В одном реальном ручном уведомлении `sys` отсутствовал.
- Возвраты, включая частичные, делаются в личном кабинете. **Webhook о возврате не предусмотрен**. Заявка о возврате не доказывает исполнение; реальная тестовая заявка 29 октября была отменена.
- Официально предложены docs самостоятельной интеграции и оплаты: https://help.prodamus.ru/payform/integracii/rest-api/instrukcii-dlya-samostoyatelnaya-integracii-servisov и https://help.prodamus.ru/payform/uvedomleniya/kak-ustroena-otpravka-uvedomlenii-ob-oplate.

## Что изменено в PR №22/№26

**Website:** EN/RU/KK: `/checkout/`, `/ru/checkout/`, `/kk/checkout/`. Серверный подписанный POST в `https://anriprod.proeducation.kz/`, `do=pay`, `currency=kzt`, `sys=anriaudio`, фиксированная цена товара, один заказ. Перед оплатой сохраняются номер заказа + личный 43-символьный код (кнопка копирует оба реквизита). Вернувшийся пользователь проверяет заказ посредством `POST /v1/checkout/proeducation/claim`, а не по URL/email. Ключ выдаётся **только на сайте**, без рассылки. Redirect с платёжной страницы не является доказательством оплаты.

**ANRI Cloud:** валидирует HMAC `Sign` из `multipart/form-data`/form-urlencoded, `payment_status=success`, настоящий merchant domain, заранее созданный случайный `order_num`, уникальный provider `order_id`, фиксированную цену/сумму и позицию. Учитывает настоящие особенности KZ callback: `sys` может отсутствовать в подписанном уведомлении для нового FULL-заказа (но неверный sys запрещён); `rub` только для подписанного RF-card уведомления при согласованной KZT-конфигурации. Ручной исторический платёж с `order_num=111`, 100 ₸, неизвестным FULL-товаром **не подходит для выдачи лицензии**. Дубль уведомления не создаёт второй ключ. Каждая FULL-лицензия бессрочна, на два устройства, без DEMO/подписки. Подтверждённые полные возвраты блокируют позднюю выдачу из `paid_hold`.

**Работающий изолированный веб-шлюз:** Render `https://anri-audio-checkout-gateway-preview.onrender.com`, сервис `srv-dbhice7lk1mc73crh5t0`, branch `feature/automatic-order-claim-20261029`, `autoDeploy=no`. Пройден HTTP smoke-check реальных EN/RU/KK страниц и отклонения некорректного POST. Продажа на preview **отключена**, backend-secret отсутствует, реальный merchant API не вызывается. Публичный `anriaudio.com` пока остаётся на старом Render Static Site.

## Что ещё нужно довести до публикации (не согласовывать заново)

1. **Фиксированная цена — утверждена 29.10.2026:** **18 000 ₸ (KZT)** к оплате через ProEducation за бессрочную FULL-лицензию. $39 USD — ориентир стоимости, не динамическая конвертация. Серверные `PROEDU_FULL_PRICE_MINOR_KZT=1800000` и `FULL_PRICE_MINOR_KZT=1_800_000` (тиыны) совпадают; браузер принимает только `amount_minor=1800000`, а платёжная форма — `products[0][price]=18000.00` и `currency=kzt`. Суммы 100, 456, 6500 KZT — только старые тесты.
2. **Постоянное хранилище лицензий:** извлечь и сохранить исторические данные старого Anri-cloud, проверить backup/restore и безопасную миграцию PostgreSQL 17. Нельзя считать доступность пустой базы доказательством переноса.
3. **Подпись клиента:** независимо сверить Ed25519 release AU/Agent и серверный издатель; синтетическая RC-подпись не является подтверждением релизного пакета.
4. **Боевой backend:** секрет HMAC доступен только серверу, реальный новый подписанный `sys=anriaudio` checkout/webhook должен быть проверен на staging или при отдельно разрешённой настоящей пробе. Не использовать ручной платёж 100 ₸ как такой тест.
5. **Маршрутизация:** когда будет разрешён запуск, перевести официальный домен на веб-шлюз с **same-origin** POST маршрутизатором и утверждённым production API. Текущий preview показывает, что схема работает, но он не заменяет доменный cutover.
6. **Операторские условия:** юридические/лицензионные страницы, поддержка, инструкция установки, механизмы предотвращения дублей и ручной сверки возвратов. Цена KZT уже согласована.

## Защита при подготовке

Нельзя включать публичный checkout, совершать реальный платёж, менять настройки мерчанта, сливать PR в `main`, обновлять production `Anri-cloud` или переносить неизвестные данные старого SQLite без резервной копии и проверки. Не изменять AU/Broker/SEND MIDI/ANRI DRUMS. Не публиковать HMAC-ключ, административные ключи, клиентские данные, credential либо лицензионные ключи.

**Единый источник серверного контракта:** [ANRI Cloud — ProEducation KZ merchant contract](https://github.com/anribitzzz10-cell/Anri-cloud/blob/feature/commercial-web-only-keys-20261029/docs/PROEDUCATION_KZ_MERCHANT_CONTRACT_20261029_RU.md).
