### Следствие для механизма выдачи $39

Сейчас платёжная форма использует KZT, а публичная цена ANRI AUDIO MIDI — $39 USD. Пока нет утверждённого серверного правила конверсии либо доступного документированного checkout с подписанной валютой, нельзя принимать произвольный числовой callback «39.00» за оплату $39. Сервис должен привязывать уведомление к СЕРВЕРНОМУ заказу, созданному с фиксированным expected_amount_minor и expected_currency и известным origin. Для фиксированного KZT-мерчанта требуется независимое подтверждение, что все оплаты данного мерчанта действительно проходят в KZT, а не полагаться исключительно на hidden input. При отсутствии подтверждения валюты FAIL CLOSED: paid не устанавливать, лицензию не создавать.

Нельзя включать «режим приёма оплаты», отправлять URL уведомления или создавать боевую ссылку до явного решения владельца. Отдельный staging обработчик может безопасно принимать искусственные тестовые данные (без FULL выдачи) и моделировать проверки цены, суммы, повторов, подписи, currency mismatch, DB outage; тестовые данные не должны называться фактически полученным Proeducation webhook.

Остаются непроверенными: API формирования подписанного checkout именно этого магазина, уникальность provider payment ID, точный алгоритм подписи с реальной фикстурой мерчанта, проверяемый источник валюты, семантика двух DEMO, контроль refund/chargeback и доставка клиенту. Для этих пунктов нужно продолжить авторизованное изучение через Work и сверку с провайдером, **без** переключения live.
