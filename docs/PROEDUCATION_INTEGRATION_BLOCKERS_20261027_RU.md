## Что проверено

- PR #11 остаётся draft; в нём сайт отключает покупку и содержит предварительную спецификацию, а не платёжный backend.

- Публичная документация Prodamus описывает HMAC SHA-256, рекурсивную сортировку полей, преобразование значений в строки и сериализацию JSON; требуется сверка с библиотекой поставщика и реальным форматом этого мерчанта: https://help.prodamus.ru/payform/integracii/rest-api/instrukcii-dlya-samostoyatelnaya-integracii-servisov
- В опубликованном примере уведомления есть сумма, order_num, order_id, домен, товары и статус success, но нет отдельного поля валюты: https://help.prodamus.ru/payform/uvedomleniya/kak-ustroena-otpravka-uvedomlenii-ob-oplate. Нельзя считать валюту USD проверенной только по цене или неподписанному параметру клиента.
- Документация различает самостоятельно включённый demo и защитный demo при отключённом провайдером live: изменение подписи относится ко второму случаю. Поэтому нельзя использовать суффикс demo как единственную границу между тестовыми и реальными лицензиями.
