# ANRI AUDIO — закрытая страница реального платного пилота 100 ₸

**29 октября 2026. Это draft-код, НЕ публичный checkout и НЕ запущенный реальный платёж.**

- RU: `/ru/pilot/`; EN: `/pilot/`; KK: `/kk/pilot/`.
- Выбранная валюта: **KZT**, фиксированная серверная цена **100 ₸**.
- Никакого email на нашей странице; телефон запрашивает платёжная
  страница ProEducation. До доступа к форме нужен приватный код приглашения
  (отдельный, не ключ лицензии).
- `POST /v1/checkout/proeducation/micro/create` на отдельный backend
  формирует только один оплачиваемый заказ, возвращает уникальный номер,
  256-битный секрет заказа и подписанные поля ProEducation.
- До отправки POST-формы к мерчанту покупатель сохраняет номер заказа и
  секрет. Эти значения **не отправляются мерчанту**, не помещаются в URL
  Success/Fail, не логируются и не отправляются по email.
- URL Success ведёт на **эту же страницу своего языка**, но не является
  подтверждением оплаты. `POST /v1/checkout/proeducation/claim`
  возвращает FULL-ключ только при `fulfilled`; при `pending` или
  `paid_hold` показывает ожидание. Повторный claim возвращает прежний ключ.
- Если ProEducation callback не содержит подписанного KZT, оператор может
  сверить настоящий платёж 100 ₸ в кабинете/выписке и один раз подтвердить
  его через отдельный защищённый admin API с журналом в PostgreSQL.
  Клиентская страница никогда не подтверждает оплату.
- Обычные сайт, публичный BUY, existing synthetic staging, Railway pilot
  456 ₸ и Telegram не изменяются.

## Защитное развёртывание

Новый отдельный frontend entrypoint:
`uvicorn staging.micro_paid_server:app --host 0.0.0.0 --port $PORT --no-access-log`.
Только `APP_ENV=micro_pilot_checkout`, отдельный `MICRO_BACKEND_ORIGIN`
и `MICRO_FRONTEND_ORIGIN` вида `https://anri-micro-*.onrender.com`.
Backend также новый, из `Anri-cloud/micro_pilot_service.py`. Предназначена
постоянная изолированная PostgreSQL, не временная Free БД синтетики.

На публичном сайте `pilot/config.js` выставляет `PILOT_ENABLED=false`;
новый приватный хост выдаёт только ему локально включённую конфигурацию.
Встроены no-store, no-referrer, CSP и отсутствие аналитики.
Ни один секрет провайдера, лицензирования или администрации не публикуется
в HTML/JS.

## Live стоп

- Не подтверждено, что ProEducation данного мерчанта допускает оплату
  **100 ₸**, а не минимальный порог.
- Документально не подтверждён KZ contract callback (merchant, Sign,
  currency KZT), поэтому автоподтверждение остаётся закрытым.
- Самое важное: текущий установленный `ANRI License Agent` может
  активировать ключ лишь в том licensing API, к которому реально обращается.
  Новый backend с собственной БД **не станет** автоматически общим сервером
  для работающего AU. Без независимой проверки маршрута/issuer/pin запуск
  заблокирован.
- Отдельная постоянная БД/два платных пилотных HTTPS-сервиса не создавались
  этим коммитом; настоящая оплата и выдача реального ключа НЕ выполнялись.
